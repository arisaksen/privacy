About Isako

Isako AS is a software company based in Harstad, Norway, founded in 2026. We design and develop mobile applications for iOS and Android using Kotlin Multiplatform.

Our focus is on building games and tools that treat users as people, not products. We believe great software can be both commercially viable and ethically built — without surveillance, manipulation, or attention harvesting.

The name Isako is short for Isaksen Koding — simple, Scandinavian, to the point.
